# AILink Demo

## Setup
1. Get free Groq key → console.groq.com
2. Paste it in `.env`
3. Run `npm install`

## Terminal Chat
```bash
node --env-file=.env terminal.mjs
```
Type questions, AI responds. Ctrl+C to exit.

## Browser Chat
```bash
node --env-file=.env server.mjs
```
Open http://localhost:3000
